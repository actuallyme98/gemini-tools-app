# Creative Studio — UI refactor

The customer's `lcg_creative_studio_v4_3_updated.html` is the business reference. Its employee names, product codes, stores, amounts and result images are examples, not production defaults.

## Application structure

- One authenticated Studio shell. No embedded chat workspace, legacy tool navigation or separate admin shell.
- Overview → Idea Board → Design Gallery → Mockup Studio → Output Library.
- Admin has Team/Store/resource management, direct thumbnail/skill library entry points and company administration (accounts, usage, audit/request logs, operational settings).
- `/#admin`, `/#admin-users`, `/#admin-runs`, `/#admin-audit`, `/#admin-settings` all stay in Studio. Employees cannot fetch admin data by opening these routes.
- Retired links resolve to the closest supported Studio page. The backend and old personal records are preserved; old conversation sharing and chat editing have no UI entry point in this release.

## Visual and interaction system

Navy navigation, neutral surfaces, orange brand accents, shared type/spacing/controls. No large marketing hero in working pages. Labels, selects, dates and inputs have consistent dimensions and separation; checkboxes use independent sizing. Forms keep keyboard focus and visible labels. Help is progressively disclosed.

On desktop, the idea wizard occupies the available viewport with persistent source/master previews, four steps, an independently scrollable form region and a fixed action area. Mockup creation has a compact metadata row and three panels: source images, scene/color choices, final requirements and submission. Saved sets open in a dialog. At narrow widths the layout stacks naturally; content is not clipped to force a desktop-sized screen on a phone. Long result libraries remain scrollable and paginated.

Existing snapshot/revision guards, autosave, approval roles, per-source selections, job idempotency, costs, known-failure continuation and uncertain-outcome reconciliation are retained. No hardcoded catalog or fake metrics.
